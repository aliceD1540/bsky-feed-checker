## なにこれ

フィードのチェックを行い、新着があればBlueskyにポスト。
ブログの更新通知として使える仕組み。

## 構造

- webフォルダ
    - フィード登録フォーム
- botフォルダ
    - 登録されたフィードをチェック、新着通知を行うBot

## 大まかな処理の流れ（案）

### Web

1. アカウント名とアプリパスワードとフィードURLを登録
    - 仮に以下のデータとする
        - アカウント：bsky.example.com
        - フィードURL：https://example.com/feed.rdf
2. 登録時にシステムアカウントからDM送信
    - 確認という名目で「新規登録データ」を取得する用

### Bot

1. DM送信履歴を確認
2. 新着があったらチェック対象フィードを新規登録
3. 登録済みフィードの新着チェック
4. 新着があれば対象アカウントでポスト
